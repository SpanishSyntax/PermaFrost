# CLI & Operations Guide

This guide provides practical commands, multi-monitor configuration recipes, theme synchronization steps, and local iteration workflows for PermaFrost.

---

## CLI Flag Reference

The `astra-airlock` launcher binary provides administrative, display configuration, and debugging commands:

| Flag | Argument | Description |
| :--- | :--- | :--- |
| `-k`, `--kiosk` | `cage` \| `hyprland` | Automatically writes kiosk configuration files for the chosen compositor to `/etc/greetd/` |
| `-s`, `--sync` | None | Syncs the invoking user's active desktop Caelestia scheme into the shared greeter cache |
| `--set-pfp` | `<file>` | Copies the specified image into `/var/cache/astra-airlock/avatars/<user>` with correct read permissions |
| `--set-wallpaper` | `<file>` | Copies a custom background image into `/var/cache/astra-airlock/wallpapers/` |
| `-c`, `--convert` | `<file>` | Parses Hyprland monitor definitions from `<file>` and outputs equivalent `astra-airlock` flags |
| `--only` | `<name>` | Disables all connected outputs except `<name>` |
| `--output` | `<name>` | Selects `<name>` as the active output target for subsequent geometry options |
| `--on` / `--off` | None | Enables or disables the currently selected output |
| `--mode` | `WxH[@RATE]` | Sets the resolution and refresh rate for the selected output |
| `--custom-mode` | `WxH[@RATE]` | Sets explicit modeline timing with exact decimal refresh rate |
| `--pos` | `X,Y` | Sets the top-left coordinate of the selected output in the global virtual desktop canvas |
| `--scale` | `<factor>` | Sets the fractional or integer scaling factor (e.g. `1`, `1.25`, `2`) |
| `--transform` | `<mode>` | Applies display rotation: `normal`, `90`, `180`, `270`, `flipped` |
| `-v`, `--version` | None | Displays version information for `astra-airlock`, `greetd`, and `quickshell` |
| `-h`, `--help` | None | Prints detailed help message and exit |

## Multi-Monitor Management

By default, the greeter displays on every active display output. You can constrain or customize display geometry by appending output flags directly to the command line in `/etc/greetd/config.toml`.

### Restricting to a Single Display

```toml
# Display only on DP-2; all other displays are powered down
command = "cage -s -- astra-airlock --only DP-2"
```

### Explicit Geometry & Scaling

```toml
# DP-1 primary 1440p 144Hz at position (0,0); HDMI-A-1 1080p 60Hz positioned right of DP-1
command = "cage -s -- astra-airlock --output DP-1 --mode 2560x1440@144 --pos 0,0 --scale 1 --output HDMI-A-1 --mode 1920x1080@60 --pos 2560,0 --scale 1"
```

## Converting Hyprland Monitor Layouts

If you have already tuned your multi-monitor layout in Hyprland, convert it automatically:

```bash
astra-airlock --convert ~/.config/hypr/monitors.conf
```

Or for Caelestia Lua configs:

```bash
astra-airlock --convert ~/.config/caelestia/hyprland-gui.lua
```

This parses `monitor = ...` lines and `hl.monitor({ ... })` blocks and outputs the matching `astra-airlock` flags:

```text
--output DP-1 --custom-mode 2560x1440@143.98Hz --pos 0,0 --scale 1 --output DP-2 --mode 1920x1080@60 --pos 2560,360 --scale 1
```

Copy the generated flags into the `command` definition in `/etc/greetd/config.toml`.

## Syncing Active Desktop Themes

The `--sync` (`-s`) flag extracts the active desktop theme generated by `caelestia-cli` and copies it into `/var/cache/astra-airlock/schemes/dynamic/<user>/`:

```bash
sudo astra-airlock --sync
```

Once synced, a **Dynamic** theme toggle appears in the greeter's settings modal. When multiple users share a machine, the greeter crossfades between each user's unique desktop color scheme as they switch accounts on screen.

### Passwordless Theme Sync via Sudoers

To enable theme updates automatically without manual password prompts, configure `/etc/sudoers.d/astra-airlock-sync`:

```text
your-username ALL=(ALL) NOPASSWD: /usr/bin/astra-airlock -s, /usr/bin/astra-airlock --sync
```

Verify non-interactive execution:

```bash
sudo -n astra-airlock --sync
```

### Automation via Caelestia Hooks

Add the sync hook to `~/.config/caelestia/cli.json`:

```json
{
  "theme": {
    "postHook": "sudo -n astra-airlock --sync"
  },
  "wallpaper": {
    "postHook": "sudo -n astra-airlock --sync"
  }
}
```

Now, every wallpaper or theme change on your desktop instantly synchronizes with the login greeter.

## Avatar Management

Profile pictures must be placed into the greeter cache to allow access by the unprivileged `greeter` user:

```bash
# Sets profile picture for the current user (inferred from SUDO_USER)
sudo astra-airlock --set-pfp ~/Pictures/avatar.png
```

Supported image formats include PNG, JPEG, and WebP.

## Testing & Local Development

You can run and debug the greeter UI directly within an active desktop session without terminating your session:

```bash
# Compile native plugin
cmake -B build -G Ninja
cmake --build build

# Launch Quickshell in test mode pointing to local plugin build
QML2_IMPORT_PATH=./build/qml quickshell -p .
```

When executed outside of a `greetd` session, PermaFrost activates simulated test mode, allowing full verification of animations, clock rendering, and UI modals without authenticating against system PAM.
